# 연구 기록 자료: 시뮬레이션 (2026-11-16)

의도를 모르는 앞차를 안전하게 추월하는 실험의 MuJoCo 시뮬 자료다. 발표·보고서에 그대로 쓸 수 있게 1920×1080 영상·캡처와 그래프를 모았다.
연구 내용은 [docs/RESEARCH.md](../../docs/RESEARCH.md).

- 코드: 브랜치 `exp/aur-overtake`, 커밋은 이 폴더를 올린 커밋 기준. 실차가 아닌 **시뮬 결과**다.
- 다시 만들기: `python sim/aur_overtake/media/make_media.py --out research_record/<날짜>_sim` (약 3분, [requirements](../../sim/aur_overtake/media/requirements.txt))
- 화면의 차: **파랑 = 추월하는 차(ego, 파랑이)**, **검정 = 앞차(leader, 검정이)**. 통로 폭 1.0 m (1/10 차량 기준 2차선 도로).

## 화면 읽는 법

| 표시 | 뜻 |
|---|---|
| 주황 반투명 상자 + `DETECTED d=…` | 파랑이가 라이다로 **인식한 앞차 영역**. d = 파랑이 앞범퍼에서 앞차 뒷면까지 측정 거리 |
| 빨강 바닥 영역 | 파랑이 **AEB 검사 영역** (진행 경로 ±0.16 m, 길이 = max(0.25 m, 속도 × 0.35 s)). 진하게 바뀌면 AEB 작동 |
| 초록 점 | 파랑이 라이다 점 (가드레일·앞차에 맞은 점) |
| 왼쪽 패널 | 파랑이 상태, 앞차가 비켜 줄 확률 P(Y) (흰 세로선 = 판단 기준 0.1 / 0.9), 거리·속도, AEB |
| 오른쪽 위 | 위에서 본 모습 (보라 선 = 추월 차선 / 양보 차선 중심) |
| 아래 자막 | 최근 일어난 일 (상태 변화, 판단 확정, 앞차 급정지) |

## 핵심 숫자 (`data/method_comparison.json`, 조건마다 20회)

| 방법 | Y 추월 성공 | Y 추월 시간 | 의도 판단 시간 | NY 추돌 | NY 주행 중 AEB/회 |
|---|---|---|---|---|---|
| a 고정 규칙 | 16/20 | 14.5 s | 4.1 s | 0 | 0.05 |
| b 소극적 (1.5 m 유지) | 0/20 | - | 판단 못 함 | 0 | 0 |
| c 공격적 (0.4 m) | 17/20 | 11.8 s | 3.0 s | **11/20** | 2.05 |
| **d 제안** | **17/20** | 12.3 s | 3.0 s | **0** | 0.25 |

한 줄로: **d는 c만큼 빨리 판단·추월하면서, a·b처럼 추돌이 없다.** b는 앞차 반응 거리(≤ 1.2 m) 밖에 머물러 앞차가 끝내 반응하지 않아 의도를 모른다.
NY에서 추월을 시도한 회차는 모든 방법에서 0이다. d의 Y 실패 3회는 d_y < 0.75 m (설계상 "안 비킨다"로 판정되는 0.667 m 근처).

## 주의

- 시뮬 차량 모델·라이다는 실차와 다르다 (운동학 모델, 수평 1줄 라이다). 실차 결과로 대체해야 한다.
- 화면의 차 모양·가드레일은 보기용이고, 라이다와 충돌 판정은 예전과 같은 판(벽)·상자를 쓴다. 기준선 252회로 결과가 바뀌지 않은 것을 확인했다.
- `data/events_d_*.txt`: 영상 회차의 이벤트 로그 원문, `data/single_runs.json`: 영상 회차 지표.
